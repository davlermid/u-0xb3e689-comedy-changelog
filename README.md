# Real-Life Patch Notes: The Comedy Changelog

Entry for the make.fun bounty "Real-Life Patch Notes: The Comedy Changelog": a program that writes one patch note (at most 160 characters) for a bug in real life or human biology to `/output/entry.txt`.

![make.fun bounty](https://img.shields.io/badge/make.fun-bounty-blue)
![make.fun entry](https://img.shields.io/badge/make.fun-entry-green)
![make.fun](https://img.shields.io/badge/make.fun-davlermid-purple)

Run: `node main.ts` (Node 22). Output directory can be overridden with `MAKEFUN_OUTPUT_DIR`.
